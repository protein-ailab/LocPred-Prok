# LocPred-Prok: Prokaryotic Protein Subcellular Localization Prediction

`LocPred-Prok` is a machine learning pipeline designed to predict the subcellular localization of prokaryotic proteins. It leverages the power of pre-trained Protein Language Models (PLMs) to generate high-quality embeddings from protein sequences, which are then used to train a robust downstream classification model.

This repository provides scripts for the complete workflow: from feature extraction to model training and evaluation.

## File Structure

```
LocPred-Prok/
├── checkpoint/
│   └── (Place your pre-trained model weights here, e.g., best_model_esm2_t6_8M_UR50D.pth)
├── data/
│   ├── full_dataset.fasta         # Training and validation data
│   └── benchmarking_dataset.fasta # Test/Benchmark data
├── precomputed_features/
│   └── (This directory will be generated by preprocess.py)
├── preprocess.py                  # Script to generate embeddings from FASTA files
├── train_and_eval.py              # Script for model training and evaluation
└── README.md
```

## Workflow & Usage

The process is divided into two main steps: preprocessing and training/evaluation.

### 1. Preprocessing: Generate Protein Embeddings

This step uses `preprocess.py` to convert the raw protein sequences from the `.fasta` files into numerical embeddings using various PLMs (e.g., ESM-2, ProtT5).

**Command:**
```bash
python preprocess.py \
  --train_fasta data/full_dataset.fasta \
  --test_fasta data/benchmarking_dataset.fasta \
  --output_dir ./precomputed_features
```

**What it does:**
* It processes both `full_dataset.fasta` and `benchmarking_dataset.fasta`.
* It creates a new directory named `precomputed_features`.
* Inside `precomputed_features`, it generates subdirectories for each PLM specified in the script (e.g., `esm2_t6_8M_UR50D`, `esm2_t12_35M_UR50D`, etc.).
* Each subdirectory will contain the protein embeddings (`.pt` files) and corresponding metadata (`.json` files).

### 2. Training and Evaluation

After generating the features, use `train_and_eval.py` for either training a new model or evaluating an existing one.

#### Option A: Train a New Model

To train the model from scratch using the precomputed features:

**Command:**
```bash
python train_and_eval.py \
  --base_feature_dir ./precomputed_features \
  --mode train
```

**What it does:**
* The script will automatically find the features for all PLMs inside the `precomputed_features` directory and run a separate training process for each.
* It splits the data from `full_dataset` into training and validation sets.
* After training, it evaluates the best model on the test set (`benchmarking_dataset`).
* The best model weights for each PLM (e.g., `best_model_esm2_t6_8M_UR50D.pth`) will be saved in the project's root directory.

#### Option B: Evaluate Using a Pre-trained Checkpoint

If you only want to run evaluation using an existing trained model without retraining:

**Setup:**
1.  Make sure you have already run the preprocessing step to generate the features in `./precomputed_features`.
2.  Place your pre-trained model files (e.g., `best_model_esm2_t6_8M_UR50D.pth`) into the project's root directory. You can also move them from the `checkpoint/` folder.

**Command:**
```bash
python train_and_eval.py \
  --base_feature_dir ./precomputed_features \
  --mode test
```

**What it does:**
* The script loads the corresponding pre-trained model weights from the root directory.
* It runs a full evaluation on the test set (`benchmarking_dataset`).
* It prints a detailed performance report, including accuracy, F1-score, Matthews Correlation Coefficient (MCC), a classification report, and a confusion matrix to the console.
